{% comment %}Shared print design system for all OpenZEV documents (invoices, contracts). Extracted from the invoice PDF template (invoices/invoice_pdf.html) so every printable document shares one visual baseline: design tokens, base typography, utilities, the single page-1 document header anatomy, and the running page-meta furniture that appears in the page margin boxes. How to use: - On-disk default templates pull this file in from their head with the Django include tag pointing at "pdf/shared_pdf_base.html", then define their own style block for document-specific rules (layout padding, summary band, tables, signatures, the document's own @page setup, ...). - This partial is intentionally NOT inlined into customised templates: a PdfTemplate DB override stores one full standalone HTML document, so existing overrides keep working untouched when the shared design changes. Only a reset to default (DELETE on the template endpoint) adopts it. - The .page-meta classes pair with "position: running(...)" elements dropped directly under and with margin boxes wired up in each document's own @page rules (see the invoice template for the pattern). {% endcomment %}
